# ربات دانلود ساندکلاد

لینک آهنگ ساندکلاد → فایل صوتی با کاور، نام همه خواننده‌ها و تگ‌های کامل.

## راه‌اندازی روی Railway
1. پروژه را روی GitHub بگذارید (توکن را داخل ریپوی عمومی نگذارید؛ بهتر است متغیر `BOT_TOKEN` را در Railway تنظیم کنید).
2. در Railway: New Project ← Deploy from GitHub repo. فایل `railway.json` و `Dockerfile` خودکار شناسایی می‌شوند.
3. توکن را یا در `main.py` (متغیر `BOT_TOKEN`) بنویسید یا در بخش Variables با نام `BOT_TOKEN` اضافه کنید.

## کار در گروه
در BotFather دستور `/setprivacy` را روی **Disable** بگذارید (یا ربات را ادمین کنید)، وگرنه ربات لینک‌های داخل گروه را نمی‌بیند. بعد از تغییر، ربات را یک‌بار از گروه حذف و دوباره اضافه کنید.

## پلی‌لیست
لینک پلی‌لیست (`/sets/`) هم پشتیبانی می‌شود: بعد از تایید، آهنگ‌ها یکی‌یکی با کاور و تگ کامل ارسال می‌شوند. سقف تعداد در `main.py` (`MAX_PLAYLIST_TRACKS` برای پیوی و `MAX_PLAYLIST_TRACKS_GROUP` برای گروه) تنظیم می‌شود. هر کاربر هم‌زمان یک پلی‌لیست فعال دارد و با دکمه «توقف» می‌تواند آن را قطع کند. آهنگ‌های خصوصی یا حذف‌شده رد می‌شوند و در پایان در خلاصه می‌آیند. لینک پروفایل هنرمند پشتیبانی نمی‌شود.

## نکته‌ها
- با هر استارت، yt-dlp به آخرین نسخه ارتقا می‌یابد (`AUTO_UPDATE_YTDLP` در `main.py`).
- محدودیت ارسال ربات‌های تلگرام ۵۰ مگابایت است.
- ظاهر پیام‌ها و نوار پیشرفت در `ui.py` است.
